# QA report: first-day warehouse staff on a 360x740 phone

Persona: no training, in a hurry, one thumb. User: demo `staff` (Warehouse staff, one warehouse "Main warehouse"). Build: web http://localhost:4200, API http://localhost:5109, throw-away QA database, 2026-10-10.
Method: built-in browser, viewport 360x740 (Chrome emulation, English, then zh and ms for the language pass). Sources read first: `docs/design/mvp-ux.md`, `web/README.md`.

Test limits (read before trusting the numbers):
- The browser pane exposed one shared tab (`seed`); I could not open my own. Other QA agents resized and navigated that tab several times, which wiped one of my drafts and made some screenshots stale or cropped. Every finding below was reproduced after re-applying the 360x740 viewport and, for the document bugs, checked in the network log (counts of POST calls) and the document lists.
- Not tested: soft keyboard covering buttons (the emulation has no on-screen keyboard), going offline (no toggle in the pane), real camera scanning (Phase 2). Tap-target sizes were not measured in the browser; I read the design tokens (`web/libs/shared/styles/.../_layout.var.scss`: touch 48px, min 44px, `button.component.scss` min-height 48px, min-width 44px) and judged by screenshot. Exception noted in NV-14.
- Demo credentials are not recorded here.

## What worked well

- Home: two large 48px buttons, plain labels, nothing else competing.
- Login: Show password eye, one clear banner, no field blamed, spinner while signing in.
- Add item: barcode Enter adds and refocuses; a miss is a quiet grey message; picker shows "N PCS available" on issues.
- Shortfall: inline red message with one-tap "Set to N", footer reason, disabled primary (design E1 matched).
- Confirm and Cancel dialogs are bottom sheets with verb buttons ("Keep document", "Cancel document", "Keep editing").
- Double tap on submit and post produced one request.
- Status chips carry icon plus text (Draft, Submitted, Posted, Cancelled); "Low" chip has a warning icon.
- Forbidden page uses the designed words and names the user's role.
- Language switch is instant and keeps the screen; zh and ms fit at 360px except one bottom-bar label.
- No horizontal scroll on any page at 360px except the tab strip in NV-23; native number input uses decimal inputmode.
