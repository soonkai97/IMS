IMS motion demo

docs/design/2026-refresh-motion.md. Hover, press, open, replay.

Your operating system asks for reduced motion, so this page started in Reduced. Choose Full to compare.

Full = everything. Lite = automatic on weak devices (no stagger, shimmer, count-up, chart draw, route fade). Reduced = the OS setting: nothing moves, only short fades. Off = test kill switch.

Buttons

Hover fades an overlay, press scales to 0.97, release springs back.

Wrong user name or password. Check both and try again.

Save: label morphs to a tick, button width never changes. Sign in: one 4px shake, none in Reduced. Busy shows a spinner after a short wait; in Reduced it shows the clock and the word.

Overlays

Dialog: spring pop. Drawer and phone sheet: edge slide, no overshoot. Scrim fades.

Narrow the window under 600px to see the dialog become a bottom sheet. Toasts stack (max 2), the survivor slides into place (FLIP). Reduced: fade only.

Tabs and segmented control

The indicator slides with transform (scaleX for the tab underline, translateX for the equal-width segments). Reduced: it jumps.

Form micro-interactions

Enter a reason.

Focus: the ring is instant, an underline grows under it. The message opens by grid rows and the text rises 4px.

List with staggered entrance and expanding row

Only the first 8 rows animate (25ms apart). Rows 9 and 10 appear at once. Click a row to expand.
